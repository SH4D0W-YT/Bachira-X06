A multipurpose Discord bot built for community server management, combining moderation, engagement, and utility tools in one place.
Features:

 :shield: Moderation — warnings, mutes (with automatic expiry), and standard mod actions, all logged
 :clipboard: Logging — tracks server events for transparency and accountability
 :wave: Welcome & DM System — greets new members and sends automated DMs for things like tickets or onboarding
 :incoming_envelope: Invite Tracker — keeps tabs on who's inviting new members
 :tada: Giveaways — fully automated entry, timing, and random winner selection
 :bar_chart: Polls — quick community polling
* :performing_arts: Reaction Roles — self*assignable roles via reactions
* :bulb: Suggestions — a channel for members to submit and vote on ideas
* :ticket: Tickets — a private support ticket system
* :tools: Utility — general*purpose commands (info, ping, etc.)
- :pick: Minecraft Integration — live server status via mcstatus
