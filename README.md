## SETUP INsTRUCTION FOR THE BOT

===================================================

## QUICK START — READ THIS FIRST

===================================================

STEP 1: Install Python 3.11+
-> https://www.python.org/downloads/
-> During install: CHECK "Add Python to PATH"
-> Restart your PC after installing

STEP 2: Set up your bot token
-> Open .env with Notepad
-> Fill it in like this (no quotes, no spaces):
DISCORD_TOKEN=paste_your_token_here
OWNER_ID=paste_your_user_id_here

STEP 3: Run the bot
-> Double-click "run.bat"
(installs all packages and starts the bot automatically)

OR open a terminal in this folder and type:
py -m pip install -r requirements.txt
py main.py

## HOW TO GET YOUR BOT TOKEN

==============================================

1. Go to https://discord.com/developers/applications
2. New Application -> give it a name -> Create
3. Click "Bot" on the left -> "Reset Token" -> copy it
4. Enable ALL THREE Privileged Intents:
   - Presence Intent
   - Server Members Intent
   - Message Content Intent
5. Go to OAuth2 -> URL Generator
   -> Scopes: bot + applications.commands
   -> Permissions: Administrator
   -> Copy the URL and open it to invite the bot

===================================================
HOW TO GET YOUR USER ID (for OWNER_ID)
===================================================

1. Discord Settings -> Advanced -> Enable Developer Mode
2. Right-click your own username anywhere -> "Copy User ID"
